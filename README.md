# visualizador-butterchurn
A humble visualizer for my songs (and yours!)

Visualizador MilkDrop em tela cheia (via [Butterchurn](https://github.com/jberg/butterchurn)) que escuta uma entrada de áudio do Mac — por padrão o **BlackHole 2ch** — para reagir à música tocada em qualquer player (como o Minamp).

Abra: https://rafaelreinehr.github.io/visualizador-butterchurn/

## Atalhos

| Tecla | Ação |
|---|---|
| F ou duplo clique | tela cheia |
| → ou Espaço | próximo preset |
| ← | preset anterior |
| L | travar/destravar o preset |
| ↑ / ↓ | sensibilidade ao áudio |
| H | mostrar/esconder o nome do preset |
| Q | qualidade máxima liga/desliga |
| D | trocar a entrada de áudio |

O áudio é processado só no navegador; nada é enviado a lugar nenhum.
